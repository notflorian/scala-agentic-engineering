# 16. Antipatrones que conviene evitar

| Antipattern                                                                         | ¿Por qué es malo?                                                                                   |
|--------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------|
| Mejora este módulo de control de velocidad                                                                 | Demasiado vago, diff ancho                                                                                   |
| Dar toda la repos                                                                 | Costo caro, ahoga la señal                                                                               |
| Dejar que el agente refactore espontáneamente                                              | Diffs difficiles à reviewer                                                                              |
| Tres agentes en la misma rama                                                     | Conflictos y pérdida de control                                                                            |
| Review IA sin spec                                                                  | Retornos genéricos                                                                                       |
| Qwen solo en código crítico                                                          | Riesgo de calidad                                                                                           |
| Claude en boilerplate trivial                                                       | Gaspillaje cuota                                                                                         |
| Compresión agresiva del código fuente                                                 | Pérdida de detalles críticos                                                                               |
| No hay pruebas específicas                                                                  | El agente se auto-convence                                                                                  |
| Ignorar IntelliJ                                                                     | Gran error en Scala/JVM                                                                               |
| Fable 5.2, GPT‑6.2 Astra `max` o `ultra` sobre tarea simple                             | Coste, latencia y cuota consumidos para cero ganancia real                                                     |
| Opus 5.5 High/Extra por defecto en cualquier tarea                                       | Opus Medium o Sonnet 5.5 Medium a menudo son suficientes; el esfuerzo alto debe comprar una ganancia medida           |
| Iniciar Fable 5.2 sin spec completo                                                  | Modelo fuerte + prompt bordo = deriva costosa                                                              |
| Sol/Astra de alto esfuerzo para PR summary                                             | GPT‑6 Luna Suficiente                                                                                        |
| Dos agentes en los mismos archivos                                       | Conflictos, diffs incoherentes, responsabilidad borrosa                                                        |
| Qwen3-Coder-Next árbitro final en código crítico                                     | Muy útil económicamente, pero no lo suficientemente seguro sin una revisión fuerte                                          |
| Tratar una salida, README, log o resultado MCP como una instrucción fiable | Injerencia indirecta y ampliación de permisos                                                      |
| Dar a un reviewer toda la transcripción de una larga sesión de agente               | Context rot: ruido histórico, tensiones ahogadas, menos buena detección de defectos                    |
| Reinyectar la carta sólo al primer prompt                                    | La deriva larga se mide; el re-anclaje periódico es el desfile (sección 5, etapa 8)               |
| Construir un flujo de trabajo en una cuota gratuita                                               | Los derechos de emisión gratuitos desaparecen sin previo aviso (Gemini CLI, junio 2026); rodar sobre superficies estables |
