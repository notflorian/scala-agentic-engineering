# 15. Criterios de finalización de una tarea agéntica en Scala

```text
- Objetivo y restricciones explícitos
- Plan validado antes de modificar
- Diff mínimo
- Ninguna refactorización fuera del alcance
- API pública conservada o cambio documentado
- Serialización JSON conservada o probada
- Pruebas específicas añadidas o actualizadas
- scalafmt / compilación / pruebas específicas correctas
- Revisión por un segundo modelo realizada
- Observaciones bloqueantes resueltas
- Riesgos residuales enumerados
- Comandos ejecutados documentados en la PR
- Cada requisito importante vinculado a una prueba; resultados y riesgos referidos al SHA candidato
- CI independiente y revisión final en los commits correctos; consulta la sección 15B para los criterios de producción
```
