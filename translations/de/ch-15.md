# 15. Abschlusskriterien für agentenbasierte Scala-Aufgaben

```text
- Ziel und Vorgaben sind ausdrücklich festgehalten
- Plan vor der Umsetzung bestätigt
- Minimaler Diff
- Kein Refactoring außerhalb des Arbeitsumfangs
- Öffentliche API unverändert oder Änderung dokumentiert
- JSON-Serialisierung unverändert oder getestet
- Gezielte Tests hinzugefügt oder aktualisiert
- scalafmt / Kompilierung / gezielte Tests erfolgreich
- Review durch ein zweites Modell abgeschlossen
- Blockierende Rückmeldungen bearbeitet
- Verbleibende Risiken aufgelistet
- Ausgeführte Befehle im PR dokumentiert
- Jede wesentliche Anforderung hat einen Beleg; Ergebnisse und Risiken beziehen sich auf den Kandidaten-SHA
- Unabhängige CI und abschließendes Review auf den richtigen Commits; für die Produktionsreife siehe Abschnitt 15B
```
