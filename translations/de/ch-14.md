# 14. Optimaler Wochenplan

<!-- section: s-1 -->
## Montag: Planung

* Tickets ausschneiden.
* Gefahren und Tests identifizieren.
* Kontexte vorbereiten Sourcebot.
* Aktualisieren Sie `AGENTS.md`, wenn eine gemeinsame Projekt-Regel fehlt; `CLAUDE.md` nur für eine spezifische Claude-Regel.
* Auf die Voranalyse wird Qwen eingeleitet.

<!-- section: s-2 -->
## Dienstag bis Donnerstag: Produktion

* 1 bis [2] große Aufgaben Claude Code pro halben Tag.
* Qwen für Boilerplate und Voranalyse.
* Codex für die review vor PR.
* Systematische gezielte Tests.
* Keine offene agentielle Aufgabe ohne Annahmekriterium.

<!-- section: s-3 -->
## Freitag: Härten

* Gesamtbeurteilung Codex.
* Ich versuche es noch weiter.
* Die Diffs sind sauber.
* Dokumentation.
* Kostenanalyse.
* Fügen Sie Hooks hinzu, wenn sich eine Art von Fehler wiederholt hat.
