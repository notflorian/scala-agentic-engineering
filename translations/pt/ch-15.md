# 15. Critérios de conclusão de uma tarefa agêntica em Scala

```text
- Objetivo e restrições explícitos
- Plano aprovado antes das alterações
- Diff mínimo
- Nenhuma refatoração fora do escopo
- API pública inalterada ou alterações documentadas
- Serialização JSON inalterada ou coberta por testes
- Testes direcionados adicionados ou atualizados
- scalafmt / compilação / testes direcionados aprovados
- Revisão por um segundo modelo concluída
- Achados bloqueantes resolvidos
- Riscos residuais listados
- Comandos executados documentados na PR
- Cada requisito importante ligado a evidências, com resultados e riscos no SHA candidato
- CI independente e revisão final nos commits corretos. Veja a seção 15B para os critérios de conclusão em produção
```
