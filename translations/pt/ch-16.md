# 16. Antipadrões a evitar

| Antipattern                                                                         | Por que é mau?                                                                                   |
|--------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------|
| Melhoria deste módulo de controlo de velocidade                                                                 | Demasiado vago, diff largura                                                                                   |
| Dar todo o relaxamento                                                                 | Custo caro, afoga o sinal                                                                               |
| Deixar que o agente refatore espontaneamente                                              | Diffs difficiles à reviewer                                                                              |
| Três agentes no mesmo ramo                                                     | Conflitos e perda de controle                                                                            |
| Revisão IA sem spec                                                                  | Retornos genéricos                                                                                       |
| Qwen apenas em código crítico                                                          | Risco de qualidade                                                                                           |
| Claude em boilerplate trivial                                                       | Gaspilhagem quota                                                                                         |
| Compressão agressiva do código fonte                                                 | Perda de detalhes críticos                                                                               |
| Não existem provas específicas.                                                                  | O agente se autoconvence                                                                                  |
| Ignorar IntelliJ                                                                     | Grande erro na Scala/JVM                                                                               |
| Fable 5.2, GPT‑6.2 Astra `max` ou `ultra` sobre tarefa simples                             | Custo, latência e quota consumidos para zero ganho real                                                     |
| Opus 5.5 High/Extra por defeito em qualquer tarefa                                       | Opus Medium ou Sonnet 5.5 Medium são muitas vezes suficientes; o esforço alto deve comprar um ganho medida.           |
| Iniciar Fable 5.2 sem spec completo                                                  | Modelo forte + prompt bordo = deriva cara                                                              |
| Sol/Astra de alto esforço para PR summary                                             | GPT‑6 Luna O suficiente                                                                                        |
| Dois agentes nos mesmos arquivos                                       | Conflitos, diffs incoerentes, responsabilidade turva                                                        |
| Qwen3-Coder-Next árbitro final em código crítico                                     | Muito útil economicamente, mas não suficientemente seguro sem uma revisão forte                                          |
| Tentar uma saída, README, log ou resultado MCP como uma instrução confiável | Inerência indirecta e ampliação de licenças                                                      |
| Dar a um reviewer toda a transcrição de uma longa sessão de agente               | Context rot: ruído histórico, tensões afogadas, menos boa detecção de defeitos                    |
| Reinyectar a carta apenas ao primeiro prompt                                    | A deriva longa é medida; o re-anclaje periódico é o desfile (secção 5, etapa 8)               |
| Construir um fluxo de trabalho numa quota gratuita                                               | Os direitos de emissão gratuitos desaparecem sem aviso prévio (Gemini CLI, Junho 2026); rodar sobre superfícies estáveis |
