# 14. Planejamento semanal ideal

<!-- section: s-1 -->
## Segunda-feira: planejamento

* Cortar os bilhetes.
* Identificar riscos e testes.
* Preparar os contextos Sourcebot.
* Actualizar `AGENTS.md` se falta uma regra de projeto comum; `CLAUDE.md` apenas para uma regra específica Claude.
* Iniciar Qwen na pré-análise.

<!-- section: s-2 -->
## Terça-feira: produção

* 1 a 2 grandes tarefas Claude Code por meio dia.
* Qwen para boilerplate e pré-análise.
* Codex para revisão prévia PR.
* Testes sistemáticos de objetivo.
* Não há trabalho operacional aberto sem critérios de aceitação.

<!-- section: s-3 -->
## Sexta: endurecimento

* Revisão global Codex.
* Testes mais amplos.
* Limpeza do 'diffs'.
* Documentação.
* Análise de custos.
* Adicionar hooks se um tipo de erro for repetido.
