# 16. Anti-patterns to avoid

| Anti-pattern                                                                         | Why it's bad                                                                                   |
|--------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------|
| Improves this module                                                                 | Too vague, wide diff                                                                                   |
| Give all the repo                                                                 | Cost expensive, drowns the signal                                                                               |
| Allow the agent to refactor spontaneously                                              | Difficult diffs to review                                                                              |
| Three agents on the same branch                                                     | Conflicts and loss of control                                                                            |
| Review IA without spec                                                                  | Generic returns                                                                                       |
| Qwen alone on critical code                                                          | Quality risk                                                                                           |
| Claude sur boilerplate trivial                                                       | Waste quota                                                                                         |
| Aggressive source code compression                                                 | Loss of critical details                                                                               |
| No targeted tests                                                                  | The agent convinces himself                                                                                  |
| Ignore IntelliJ                                                                     | Serious error on Scala/JVM                                                                               |
| Fable 5.2, GPT‑6.2 Astra `max` or `ultra` on a simple task                             | Cost, latency and quota consumed for zero real gain                                                     |
| Opus 5.5 High/Extra default on any task                                       | Opus Medium or Sonnet 5.5 Medium often suffice; high effort must buy a measured gain           |
| Launch Fable 5.2 without full spec                                                  | Strong model + quick blur = expensive drift                                                              |
| High-effort soil/Astra for PR summary                                             | GPT‑6 Luna is enough                                                                                        |
| Two writing agents on the same files                                       | Conflicts, incoherent differences, blurred responsibility                                                        |
| Qwen3-Coder-Next final arbitrator on critical code                                     | Very useful economically, but not sure enough without strong review                                          |
| Treat an exit, README, log or result MCP as a reliable instruction | Indirect injection and extension of permissions                                                      |
| Give a reviewer the entire transcript of a long session of agentics               | Context rots: historical noise, drowned stresses, less good fault detection                    |
| Re-inject charter only at first prompt                                    | The long drift is measured; the periodic re-anchoring is the parade (section 5, step 8)               |
| Build a workflow on a free quota                                               | Free quotas disappear without notice (Gemini CLI, June 2026); route on stable surfaces |
