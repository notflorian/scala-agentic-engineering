# 14. An effective weekly schedule

<!-- section: s-1 -->
## Monday: planning

* Cut the tickets.
* Identify risks and tests.
* Prepare contexts Sourcebot.
* Update `AGENTS.md` if a common draft rule is missing; `CLAUDE.md` only for a specific Claude rule.
* Launch Qwen on pre-analysis.

<!-- section: s-2 -->
## Tuesday to Thursday : production

* 1 à 2 large tasks Claude Code half-day.
* Qwen for boilerplate and pre-analysis.
* Codex for review before PR.
* Systematic targeted tests.
* No open agent task without acceptance criteria.

<!-- section: s-3 -->
## Friday: hardening

* Global Review Codex.
* Wider tests.
* Diffs cleaning.
* Documentation.
* Cost analysis.
* Added hooks if a type of error has repeated itself.
