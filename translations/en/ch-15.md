# 15. Definition of done for an agentic Scala task

```text
- Goal and constraints stated explicitly
- Plan approved before changes
- Minimal diff
- No refactoring outside scope
- Public API unchanged or changes documented
- JSON serialization unchanged or tested
- Targeted tests added or updated
- scalafmt / compilation / targeted tests pass
- Review by a second model completed
- Blocking findings addressed
- Residual risks listed
- Commands run documented in the PR
- Every important requirement linked to evidence, with results and risks tied to the candidate SHA
- Independent CI and final review on the correct commits. See section 15B for production completion criteria
```
