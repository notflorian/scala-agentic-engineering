# 16. Antipattern da evitare

| Anti-patternologicamente                                                                         | Perché è maleducato                                                                                   |
|--------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------|
| Migliora questo modulo urgente                                                                 | Troppo vago, ampio diffrazione                                                                                   |
| Dare a tutti i repo necessari                                                                 | Costo costoso, annega il segnale dovuto                                                                               |
| Consentire all'agente di rifare spontaneamente                                              | Difficili difficili da rivedere                                                                              |
| Tre agenti sullo stesso ramo casuale                                                     | Conflitti e perdita di controllo                                                                            |
| Recensione IA senza spec precedenti                                                                  | Responsabili generici                                                                                       |
| Qwen da solo su codice critico                                                          | Rischio di qualità                                                                                           |
| Claude sur boilerplate trivializzazione                                                       | Rifiuti contingenti                                                                                         |
| Aggressivo codice sorgente compressione                                                 | Perdita di dettagli critici                                                                               |
| Nessun test mirato                                                                  | L'agente si convince a rinunciare                                                                                  |
| Ignora IntelliJ]                                                                     | Errore serio su Scala/JVM casuale                                                                               |
| Fable 5.2, GPT‑6.2 Astra `max`] o `ultra` su un semplice compito                             | Costo, latenza e quota consumati per zero reale guadagno compensativo                                                     |
| Opus 5.5 Predefinizione High/Extra su qualsiasi task                                       | Opus Medium o medio Sonnet 5.5 Media spesso sufficiente; alto sforzo deve comprare un guadagno misurato           |
| Avviare Fable 5.2 senza pieno spec casual                                                  | Modello forte + smussatura rapida = costosa deriva                                                              |
| Terreno ad alto sforzo/Astra per PR sommario                                             | GPT‑6 Luna è sufficiente                                                                                        |
| Due agenti di scrittura sugli stessi file precedenti                                       | Conflitti, differenze incoerenti, responsabilità offuscata                                                        |
| Qwen3-Coder-Next arbitro finale su codice critico                                     | Molto utile economicamente, ma non abbastanza sicuro senza recensione forte                                          |
| Trattare un'uscita, README, log o risultato MCP come istruzioni affidabili | Iniezione indiretta e estensione delle autorizzazioni necessarie                                                      |
| Dare un recensore l'intera trascrizione di una lunga sessione di agentics precedenti               | Marciumi di contesto: rumore storico, stress annegati, meno buon rilevamento guasti                    |
| Re-iniettare il noleggio solo al primo prompt anticipato                                    | La lunga deriva è misurata; il ri-anchoring periodico è la parata (sezione 5, passo 8)               |
| Costruire un flusso di lavoro su una quota aggiuntiva gratuita                                               | Le quote libere scompaiono senza preavviso (Gemini CLI, giugno 2026); percorso su superfici stabili |
