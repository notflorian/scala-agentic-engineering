# 15. Criteri di completamento per un’attività agentica in Scala

```text
- Obiettivo e vincoli esplicitati
- Piano approvato prima delle modifiche
- Diff minimo
- Nessun refactoring fuori perimetro
- API pubblica invariata o modifica documentata
- Serializzazione JSON invariata o con test
- Test mirati aggiunti o aggiornati
- scalafmt / compile / test mirati passati
- Revisione con un secondo modello completata
- Rilievi bloccanti risolti
- Rischi residui elencati
- Comandi eseguiti documentati nella PR
- Ogni requisito importante associato a un’evidenza; risultati e rischi riferiti allo SHA candidato
- CI indipendente e revisione finale sui commit corretti; vedi la sezione 15B per i criteri di completamento in produzione
```
